# Исправление входа — 1.0.2

Собственник создаётся с почтой или обычным логином. Кириллица в имени разрешена.
Почта нормализуется без учёта регистра, допускается длина до 254 символов.
Вход не обрезает длинный адрес. Сброс пароля также принимает почту.
На странице входа добавлена кнопка «Показать / Скрыть» пароль.

Распакуйте патч в корень проекта с заменой файлов.
Зависимости и структура БД не менялись: npm ci и миграции не нужны.
Если собственник ещё не создан:

```bat
npm run user:create
```

Введите имя, затем свою почту в поле «Email или логин», пароль и повтор пароля.
Далее:

```bat
npm run build
npm run dev
```

Если сервер уже запущен, остановите его Ctrl+C и запустите снова.
Существующая база, .env и загруженные фотографии патчем не изменяются.
Проверки: создание/вход по почте, включая адрес длиннее 80 символов,
нормализация регистра, переключение видимости с сохранением значения пароля.
