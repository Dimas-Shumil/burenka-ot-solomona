## Ограничения проверки

Удалённый браузер не смог подключиться к localhost среды, а запуск локального
Chromium заблокирован ограничениями окружения. Поэтому визуальная проверка на
desktop/mobile и реальная установка PWA/обновление на Windows/Android/iOS здесь
не подтверждены. Эти проверки нужно выполнить после запуска на компьютере.
Не заявляем измеренные Core Web Vitals, подтверждённую работу тайлов внешней карты,
реальную геолокацию, живой TLS, индексацию, позиции в поиске и нагрузочные показатели.

## До production

1. Запустить комплект с нуля по README и проверить интерфейс на вашем ПК/телефоне.
2. Проверить реальную продукцию, фото, документы, реквизиты и контакты.
3. Внести координаты всех реальных магазинов, проверить маршрут и отказ геолокации.
4. Проверить заявление → новая заявка в админке → изменение статуса.
5. Подключить реальный домен, TLS, PM2, nginx, права на файлы, внешние бэкапы.
6. Проверить установку PWA и обновление без потери несохранённой формы.
7. После проверки контента включить SEO_INDEXABLE и подключить панели вебмастеров.

Это комплект для локального запуска и подготовки к публикации, а не утверждение,
что реальная инфраструктура и бизнес-контент уже настроены.

## Техническая доводка 1.0.1

По уточнению пользователя показатели «100+ продуктов», год начала работы и
остальные утверждённые информационные блоки сохранены, редактор этих сведений
не добавлялся.

Исправлено:
- Все внутренние ссылки и вход ведут на /admin/ внутри scope PWA. Старый
  /admin после входа перенаправляется на /admin/ с сохранением query.
- Первичная активация SW не перезагружает редактор. Обновление из другой вкладки
  не теряет форму; обновление применяется по кнопке с подтверждением.
- CSS/JS/иконки получают версию сборки в URL. Manifest проверяется без кеша.
- При истечении сессии редактор остаётся открыт. Вход можно выполнить в новой
  вкладке; изменившийся CSRF обновляется перед одним повтором сохранения.
  Приватные черновики не записываются в localStorage/sessionStorage.
- Сохранение не принимает ссылки на отсутствующие фотографии.
- Публичные URL с конечным слешем перенаправляются на канонические с сохранением
  поиска; исправлено различение страниц privacy/consent/search.
- Основной SEO-заголовок из настроек применяется на главной; Open Graph получает
  изображение товара/точки/страницы.
- Ошибки внешней подложки карты имеют понятное сообщение; адреса остаются доступны.

Добавлены клиентские сценарии PWA и API редактора, проверки scope, версии
ресурсов, канонических URL и отсутствующих фото. Полный набор: 23 теста
(16 интеграционных и 7 клиентских). Живая визуальная проверка и установка на
физических устройствах по-прежнему требуют доступного браузера/устройства.
