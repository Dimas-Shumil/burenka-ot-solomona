# Функциональный объём — Бурёнка от SOLOMONA

## Публичная часть

| URL | Поведение |
| --- | --- |
| / | Управляемый hero, категории, избранная собственником продукция, точки, акции, B2B |
| /catalog | Опубликованная продукция, категория, запрос, сортировка, пагинация |
| /catalog/:category | Индексируемая страница опубликованной категории |
| /product/:slug | SSR-товар, фото, вкладки, производитель, характеристики, рекомендации |
| /sales | Вертикальные рекламные плашки с действующими периодами |
| /partners | B2B-презентация и форма сотрудничества |
| /stores | Карта, список, добровольная геолокация, сортировка по расстоянию |
| /stores/:slug | Собственный URL точки, галерея, адрес, график, телефон, маршрут |
| /about | Исходный визуальный стиль и основной управляемый контент компании |
| /contacts | Общие контакты, реквизиты, форма обращения |
| /search | Поиск по названию/категории/производителю/описанию/составу/региону |
| /privacy, /consent | Тексты документов из настроек |
| /robots.txt, /sitemap.xml | Политика индексации и опубликованные URL |
| /health/live, /health/ready | Доступность процесса и схемы базы |

Цены можно скрыть. Нет кнопок покупки и информации об остатках.
Дополнительные характеристики необязательны. Неопубликованные записи дают 404.
Старые `.html` адреса перенаправляются на актуальные маршруты.

## Собственник

`/admin` → обзор, продукция, категории, производители, торговые точки, акции,
заявки, контент, настройки. Все операции проверяются на сервере. Регистрации нет.
Продукты и точки: несколько фото с порядком и обложкой. Категории и акции:
одно изображение. Публикация через checkbox, сортировка через числовое поле.
Заявки: NEW / IN_PROGRESS / CLOSED, внутренняя заметка, фильтр статуса.

## Границы

Отсутствуют: магазин/корзина/избранное посетителя, заказ/оплата/доставка, остатки,
склад, касса, лояльность, кабинеты покупателей/поставщиков, сотрудники и другие
роли, аналитика посещений, публичное PWA, PDF-каталоги, CRM и push.
Публичные страницы производителей и отдельные страницы акций не создаются.

## Требует реальных исходных данных

Демонстрационные названия, составы, цены, иллюстрации, адреса и графики нельзя
считать подтверждёнными сведениями компании. Собственник должен проверить и
дополнить их, добавить координаты и остальные точки, контакты и документы.
Оформление использует исходные изображения и зелёно-кремовую гамму макета.
Декоративные блоки сохраняются в HTML, CMS управляет основным контентом и данными.

Форма включается только после заполнения оператора, политики и согласия.
Система не генерирует фиктивные реквизиты и тексты согласия от имени организации.
